# 回归样本说明

`datasets/` 用于文档解析、抽取和图谱流程的本地回归。它同时包含 Git 跟踪样本和被忽略的补充语料，不能直接整体上传。

## 当前分类

| 内容 | 当前处理 |
| --- | --- |
| 已跟踪的环境、职位、统计公报等 Excel/Word/Markdown/TXT 样本 | 保留现有回归用途；新增或对外分发前记录来源和许可 |
| `datasets/Excel/糖尿病患者数据.xlsx` | 按维护者选择停止跟踪，本地保留 |
| `datasets/PDF/` 下第三方 PDF，包括书籍序言节选 | 按维护者选择停止跟踪，本地保留 |
| 批量 case 目录、解析碎片和运行导出 | 仅本地，不上传 |

本次检查了现有工作簿表头。患者工作簿含就诊 ID、患者编号及医疗属性；仅检查表头不能证明已完成脱敏。其余既有样本也尚无逐项来源清单，本说明不将它们认定为已获得再分发许可。

## 回归依赖

`frontend/e2e/knowledge-nexus-live-multidoc.mjs` 引用了患者工作簿；`frontend-app/e2e/module2-mobile-web-eval.mjs` 的 PDF 用例引用了书籍节选。现有本地文件保留，因此本地路径不变。新克隆仓库需要自行准备获准使用的对应语料，或先将相关用例改为使用已获准的替代样本。

这类在线集成回归不应被当作无需数据库、模型服务或本地语料即可运行的单元测试。

新增样本应提供来源、许可或内部共享范围、是否含个人信息、脱敏方式和所支持的回归用例。需要患者记录、私人文档或第三方全文时，优先在本地准备；可共享回归样本应尽量使用合成内容。
